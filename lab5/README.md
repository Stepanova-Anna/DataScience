# Лабораторная работа: Линейное Программирование в Задачах Оптимизации

## Теоретическая часть

Линейное программирование (ЛП) — раздел математического программирования, посвящённый оптимизации линейных целевых функций на множествах, задаваемых линейными равенствами и неравенствами. Основные методы решения: симплекс-метод (перебор вершин многогранника) и методы внутренней точки (движение через внутренность области). В Python для решения задач ЛП используется функция `linprog` из модуля `scipy.optimize`.

# Задача 1: Оптимизация производства электроники

## 1.1. Математическая модель

### Переменные решения:
- `x₁` — количество смартфонов, производимых за месяц
- `x₂` — количество планшетов, производимых за месяц

### Целевая функция (максимизация прибыли):
```
P(x₁, x₂) = 8000·x₁ + 12000·x₂ → max
```

### Ограничения:
1. По процессорному времени: `2·x₁ + 3·x₂ ≤ 240`
2. По оперативной памяти: `4·x₁ + 6·x₂ ≤ 480`
3. По аккумуляторам: `1·x₁ + 2·x₂ ≤ 150`
4. Условия неотрицательности: `x₁ ≥ 0, x₂ ≥ 0`

## 1.2. Функция Лагранжа

### Приведение к канонической форме для минимизации:

Для использования `linprog` преобразуем задачу максимизации в минимизацию:
```
f(x) = -8000·x₁ - 12000·x₂ → min
```

Ограничения в виде `gᵢ(x) ≤ 0`:
1. `g₁(x) = 2x₁ + 3x₂ - 240 ≤ 0`
2. `g₂(x) = 4x₁ + 6x₂ - 480 ≤ 0`
3. `g₃(x) = x₁ + 2x₂ - 150 ≤ 0`
4. `g₄(x) = -x₁ ≤ 0`
5. `g₅(x) = -x₂ ≤ 0`

### Функция Лагранжа:
```
L(x, μ) = -8000·x₁ - 12000·x₂ + μ₁·(2x₁ + 3x₂ - 240) + μ₂·(4x₁ + 6x₂ - 480) + μ₃·(x₁ + 2x₂ - 150) + μ₄·(-x₁) + μ₅·(-x₂)
```

где `μᵢ ≥ 0` — множители Лагранжа.

### Экономический смысл множителей Лагранжа (теневые цены):

- **μ₁** (процессорное время): показывает, на сколько увеличится максимальная прибыль при увеличении запаса процессорного времени на 1 час
- **μ₂** (оперативная память): показывает ценность дополнительного 1 ГБ оперативной памяти
- **μ₃** (аккумуляторы): показывает ценность дополнительного 1 аккумулятора
- **μ₄, μ₅** (неотрицательность): показывают, насколько изменится прибыль при ослаблении ограничений на неотрицательность

## 1.5. Анализ результатов

### a) Интерпретация решения:
- **Оптимальный план**: производить 150 смартфонов и 0 планшетов
- **Максимальная прибыль**: 1,200,000 рублей
- **Причина**: смартфоны дают 8000 руб./ед., планшеты — 12000 руб./ед. Однако планшет требует в 2 раза больше аккумуляторов (2 шт. вместо 1), в 2 раза больше памяти (6 ГБ вместо 4 ГБ) и в 1.5 раза больше процессорного времени. Сравнение эффективности: смартфон даёт 8000/1=8000 руб./аккумулятор, планшет — 12000/2=6000 руб./аккумулятор. Смартфон эффективнее использует дефицитные ресурсы.

### b) Анализ использования ресурсов:
| Ресурс | Использовано | Запас | Использование | Статус |
|--------|--------------|-------|---------------|--------|
| Процессорное время | 300 ч | 240 ч | 125% | Активное (дефицитный) |
| Оперативная память | 600 ГБ | 480 ГБ | 125% | Активное (дефицитный) |
| Аккумуляторы | 150 шт | 150 шт | 100% | Активное (дефицитный) |

**Все три ресурса являются активными ограничениями**. Это означает, что в точке оптимума все ресурсы используются полностью, и любое увеличение любого ресурса приведёт к росту прибыли (что подтверждается положительными множителями Лагранжа).

### c) Чувствительность решения:

**Увеличение процессорного времени на 10 часов (с 240 до 250):**
- Так как ограничение активное, прибыль возрастёт
- Прирост ≈ 8000 × 10/2 = 40,000 руб. (примерно, так как структура решения может измениться)

**Наиболее дефицитный ресурс** — аккумуляторы: на 1 дополнительный аккумулятор можно произвести 1 дополнительный смартфон, что даёт 8,000 руб. дополнительной прибыли. При этом процессорное время и память также полностью используются.

# Задача 2: Оптимизация снабжения военных баз

## 2.1. Математическая модель

### Переменные решения:
- `x₁₁` — МТО со Склада 1 на Базу Альфа
- `x₁₂` — МТО со Склада 1 на Базу Бета
- `x₁₃` — МТО со Склада 1 на Базу Гамма
- `x₂₁` — МТО со Склада 2 на Базу Альфа
- `x₂₂` — МТО со Склада 2 на Базу Бета
- `x₂₃` — МТО со Склада 2 на Базу Гамма

### Целевая функция (минимизация транспортных расходов):
```
Z = 8·x₁₁ + 6·x₁₂ + 10·x₁₃ + 9·x₂₁ + 7·x₂₂ + 5·x₂₃ → min
```

### Ограничения:

**По запасам на складах (весь запас должен быть вывезен):**
- Склад 1: `x₁₁ + x₁₂ + x₁₃ = 150`
- Склад 2: `x₂₁ + x₂₂ + x₂₃ = 250`

**По потребностям баз (каждая база должна получить необходимое количество):**
- База Альфа: `x₁₁ + x₂₁ = 120`
- База Бета: `x₁₂ + x₂₂ = 180`
- База Гамма: `x₁₃ + x₂₃ = 100`

**Условия неотрицательности:** `xᵢⱼ ≥ 0` для всех i, j

## 2.2. Проверка сбалансированности

- **Общий запас на складах**: 150 + 250 = 400 тонн
- **Общая потребность баз**: 120 + 180 + 100 = 400 тонн

**Вывод**: Задача **сбалансирована (закрытая)**, так как сумма запасов равна сумме потребностей.

## 2.3. Функция Лагранжа

Для задачи с ограничениями-равенствами:

```
L(x, λ, ν) = Z(x) + λ₁·(x₁₁ + x₁₂ + x₁₃ - 150) + λ₂·(x₂₁ + x₂₂ + x₂₃ - 250) 
            + ν₁·(x₁₁ + x₂₁ - 120) + ν₂·(x₁₂ + x₂₂ - 180) + ν₃·(x₁₃ + x₂₃ - 100)
```

В развёрнутом виде:
```
L = 8x₁₁ + 6x₁₂ + 10x₁₃ + 9x₂₁ + 7x₂₂ + 5x₂₃ 
  + λ₁(x₁₁ + x₁₂ + x₁₃ - 150) + λ₂(x₂₁ + x₂₂ + x₂₃ - 250)
  + ν₁(x₁₁ + x₂₁ - 120) + ν₂(x₁₂ + x₂₂ - 180) + ν₃(x₁₃ + x₂₃ - 100)
```

### Экономический смысл множителей Лагранжа:

- **λᵢ (потенциалы складов)**: показывают, на сколько изменится минимальная стоимость при увеличении запаса на i-м складе на 1 тонну. Это "ценность" дополнительной тонны МТО на складе.
- **νⱼ (потенциалы баз)**: показывают, на сколько изменится минимальная стоимость при увеличении потребности j-й базы на 1 тонну. Это "стоимость" доставки дополнительной тонны на базу.

# Ответы на контрольные вопросы

**1. В чём отличие задачи максимизации от задачи минимизации при использовании функции linprog?**

Функция `linprog` решает только задачи минимизации. Для максимизации необходимо умножить коэффициенты целевой функции на -1 и решить задачу минимизации. Полученное значение `fun` затем умножается на -1 для получения максимального значения.

**2. Что такое множители Лагранжа и какой экономический смысл они имеют?**

Множители Лагранжа — это коэффициенты в функции Лагранжа, соответствующие ограничениям. Экономический смысл: они показывают, на сколько изменится оптимальное значение целевой функции при изменении правой части соответствующего ограничения на 1 единицу. Это "теневые цены" ресурсов.

**3. Какие условия должны выполняться в точке оптимума согласно условиям ККТ?**

1. Стационарность: градиент функции Лагранжа по x равен нулю
2. Допустимость по прямому решению: точка удовлетворяет всем ограничениям
3. Допустимость по двойственному решению: множители для неравенств неотрицательны (μᵢ ≥ 0)
4. Дополняющая нежёсткость: μᵢ·gᵢ(x) = 0 для всех i

**4. Что такое активное ограничение и как его определить из решения?**

Активное ограничение — это ограничение, которое в точке оптимума выполняется как строгое равенство. Определяется по решению: если левая часть ограничения равна правой (с точностью до погрешности вычислений), ограничение активно.

**5. В чём разница между симплекс-методом и методами внутренней точки?**

- **Симплекс-метод**: перебирает вершины многогранника допустимой области, двигаясь вдоль рёбер к оптимуму
- **Методы внутренней точки**: движутся через внутренность допустимой области, не перебирая вершины. Более эффективны для больших задач

**6. Что такое двойственная задача и какая связь между прямой и двойственной задачами?**

Двойственная задача — это задача, построенная из исходной (прямой) путём замены переменных на множители Лагранжа. Связь: оптимальное значение прямой задачи равно оптимальному значению двойственной (теорема двойственности).

**7. Как проверить, является ли транспортная задача сбалансированной?**

Суммируем все запасы на складах и все потребности баз. Если суммы равны — задача сбалансирована (закрытая). Если не равны — несбалансирована (открытая).

**8. Что делать, если транспортная задача несбалансированная?**

- Если запасы > потребности: добавить фиктивного потребителя с потребностью = разнице и нулевой стоимостью перевозки
- Если потребности > запасы: добавить фиктивного поставщика с запасом = разнице и нулевой стоимостью перевозки
